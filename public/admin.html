Virtual Account Setup Tutorial
How this works: Each user can be assigned a permanent Nigerian virtual bank account number (powered by Flutterwave). When anyone sends money to that account number, the user's Rado Social Hub wallet is credited automatically — no screenshot needed, no manual approval.
Step 1 — Environment Variables (set once in Render/Railway):
  • FLW_PLATFORM_BVN — Your BVN (already set to your number)
  • FLW_V3_SECRET_KEY — Your Flutterwave secret key (must already be set for payments)
  • FLW_WEBHOOK_HASH — A secret string you create, then add to Flutterwave dashboard

Step 2 — Flutterwave Dashboard Webhook:
  1. Go to flutterwave.com Settings Webhooks
  2. Set webhook URL to: https://YOUR-SITE.com/api/webhooks/flutterwave
  3. Set Secret Hash to the same value as your FLW_WEBHOOK_HASH env var
  4. Tick charge.completed event and save

Step 3 — Create accounts for users:
  • Use the "Find User & Create Account" tool below
  • Or use the "All Virtual Accounts" list to manage existing ones

Step 4 — Enable/disable:
  • Toggle individual users on/off with the Enable/Disable buttons
  • Use the global kill-switch to turn off ALL virtual accounts at once (e.g. maintenance)
Global Virtual Account Switch
This kills ALL virtual account deposits instantly — useful for maintenance or if there's a fraud issue. Individual accounts stay in the database; they just stop accepting payments until you re-enable.
